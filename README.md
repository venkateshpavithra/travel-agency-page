# 🌍 Travel Agency Page

A clean and simple HTML-based Travel Agency webpage created as part of my front-end development learning journey. This project focuses on mastering core HTML concepts, semantic tags, accessibility, and proper webpage structure.

---

## 🚀 Live Demo  
View the published webpage here:  
👉 **https://venkateshpavithra.github.io/travel-agency-page/**

---

## 📜 Project Overview

This project demonstrates:

- Proper use of HTML5 semantic elements  
- Organized page structure using headings, paragraphs, lists, and figures  
- External links with safe target behavior  
- Image usage with alt text  
- Basic understanding of website layout without CSS  
- Deployment using GitHub Pages
